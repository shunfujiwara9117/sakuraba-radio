Spotify / Apple Podcasts で聴けるようにする(登録は最初の1回だけ)

下の「RSSのURL」は、Spotify や Apple の登録画面に貼り付けるための住所です。 ブラウザで開くものではありません(開くと文字だらけの画面になりますが、故障ではありません)。

✓ コピーしました
Spotify for Creators を開く Apple Podcasts Connect を開く

Spotify:

  1. 上のボタンで Spotify for Creators を開き、Spotify アカウントでログインします
  2. 「番組を追加」→「RSSフィードで配信(既存のポッドキャストを追加)」を選びます
  3. 「コピー」した RSS の URL を貼り付けます
  4. 番組設定のメールアドレスに届く認証コードを入力し、内容を確認して送信します

Apple Podcasts:

  1. 上のボタンで Apple Podcasts Connect を開き、Apple ID でサインインします
  2. 「+」→「RSSフィードのある番組を追加」を選びます
  3. 「コピー」した RSS の URL を貼り付けて「追加」→「審査用に提出」します

一度登録すれば、以後は新しいエピソードが自動で配信されます。

このページはアプリの「配信を更新」で自動的に最新になります。反映まで数十秒〜数分かかることがあります。
