# sakuraba-radio

櫻庭露樹「開運ラジオ」Podcast 配信用フィード・音声ホスティング(GitHub Pages)。

- `index.html` — 番組ページ(人がブラウザで見るページ。feed.xml を読んでエピソード一覧を表示)
- `feed.xml` — Podcast RSSフィード(Spotify / Apple Podcasts 登録用)
- `feed.xsl` — feed.xml をブラウザで直接開いたときの表示用スタイル
- `episodes/` — 配信エピソード音声

上記はすべて「櫻庭露樹AI Bot」の「配信を更新」ボタンから自動同期される。手で編集しないこと。
